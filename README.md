# AR-Implementation-Group-8

Group 8 AR implementation for a Hiro marker scene with animated 3D objects, interactive components, and a live status banner.

## Included assets

- 3D model: Box Textured from the Khronos glTF Sample Assets collection.

## How to run

Open [main.html](./main.html) in a browser served over localhost (for example: `python -m http.server 8000` and then browse to `http://localhost:8000/main.html`).

## Marker interactions

- The orange sphere changes colour each time it is tapped.
- The yellow cylinder toggles between a normal and enlarged scale when tapped.
- The status banner changes text and colour when the Hiro marker is found or lost.
